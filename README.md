## 💻 Projetos

### 🍽️ Restaurant Rest

Sistema web para gerenciamento de pratos desenvolvido com React e Java/Spring Boot.

**Funcionalidades:**

* Cadastro de pratos
* Listagem
* Edição
* Exclusão
* Validação de dados
* Persistência no banco de dados
* Integração entre Front-end e Back-end através de API REST

**Tecnologias:** React, JavaScript, Vite, CSS Modules, Axios, Java, Spring Boot, JdbcTemplate e H2.

🔗 [Acessar projeto](https://github.com/RafaelSouza115/RestaurantRest)
